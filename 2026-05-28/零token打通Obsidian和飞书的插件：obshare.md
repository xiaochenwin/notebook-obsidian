著有《思维力》《学习力》《减法》

你在 Obsidian 里写完一篇图文并茂的笔记，截图、表格、代码块一应俱全，但想分享给同事看时，你可能就傻眼了。

飞书文档可以一键分享链接，对方打开就能看。

![[笔记同步助手/images/bbfae58d9f2cf212d7a13527ae452e75_MD5.png]]

但 Obsidian 的笔记是本地 Markdown 文件。

发文件过去吧，图片路径全乱；

导出 PDF 吧，排版又丑；

贴到飞书里手动重新排版吧，一篇上万字带二十张图的笔记至少得耗掉你半个小时。

也许你会想：让 AI Agent（比如 Openclaw、Harness、Claude Code 等）帮我自动同步不就行了？

确实可以，就是费钱。

因为 Agent 要做这件事，得先把你的 Markdown 笔记整个读进上下文，再调用飞书 API 逐块创建文档。

一篇长文动辄上万个 token，更别提每张图片还要额外读写传输。

如果你笔记里有几十张截图，Agent 来回处理图片的 token 消耗会让你血压飙升。

**有没有一种方法：你写完笔记，一键就能把它变成飞书文档链接？而且不耗 token？**

有，就是今天要说的 obshare 插件。

01

这个插件做了什么？

obshare 是 Obsidian 社区插件，功能一句话说清楚：

**一键把你的 Obsidian 笔记上传到飞书，自动生成飞书文档链接，图片、表格、代码块、Mermaid 图表全部完整保留。**

这个插件的核心能力，比你想象的更完整：

![[笔记同步助手/images/609b162105b50a44e6e1fd03573d77e6_MD5.png]]

整个过程，你只需要在Obsidian笔记页面点一下按钮（如下图）：

![[笔记同步助手/images/bafda6d3de34e9756cae3e427d962a81_MD5.png]]

之后它就自动上传到你的飞书文档里了。

![[笔记同步助手/images/55564a4776df5a0c4d775a0391efc291_MD5.jpg]]

整个过程，**不需要打开飞书网页、不需要手动复制粘贴、不需要花费任何token。**

也就是说，飞书文档分享有多方便，obshare 就让你的 Obsidian 笔记分享变得多方便。

对方收到一个飞书链接，打开就是排版精美的文档，跟你直接在Obsidian里看到的几乎一模一样。

02

安装方法

安装也很简单，不需要任何命令行操作。

打开 Obsidian，进入 **设置 → 社区插件市场 → 浏览**，搜索 **“obshare”**，点击安装，再点启用。

注意：如果看不到社区插件市场选项，需要先在设置中关闭安全模式（安全模式会禁用所有第三方插件）。

安装好之后，需要配置飞书应用的凭证：

1、前往飞书开发者后台（https://open.feishu.cn/app?lang=zh-CN） ，创建一个**自建应用**

2、开通应用对**飞书文档**的读写权限（`docx:document` 和 `drive:drive`）

3、获取 **App ID** 和**App Secret**，填入插件设置页面

4、选一个飞书知识空间（或文件夹），填入 **Folder Token**

配置完成后，在 Obsidian 里打开任意笔记，右上角的「更多选项」菜单栏里会多出一个「分享该页面」的选项——点击即可上传。

整个过程配置一次，后续使用完全无感。

03

YouCore改进版obshare插件

obshare 很好用，但目前的版本有个不足。

比如你写了一篇笔记《项目管理心得》，上传到飞书后得到了链接 A，发给了同事。

三天后你对笔记做了补充修改，再次点击上传。

结果呢？插件给你生成了一个新的飞书文档，链接 B。

链接 A 还是修改前的版本，链接 B 是修改后的版本。

同事手里的链接 A 是旧的，你自己要看最新版又得记一个新链接。

**每次上传同一篇笔记，都会生成一个全新的飞书文档链接。**

原因很简单：原版 obshare 的上传逻辑是新建文档，不管你是不是传过同名的笔记，每次都是一个全新的文档，互不关联。

这对于写完就定稿不再改的笔记还好，但对于工作中持续迭代的文档——操作指引、技术方案、会议纪要——这就是个灾难。

链接满天飞，根本不知道哪个是最终版。

为了解决这个问题，我们YouCore针对这个插件，做了一个关键的功能升级——**增量更新模式**（Smart Update）。

插件会维护一份**上传历史记录**（uploadHistory），记录每一篇笔记对应哪个飞书文档。

数据结构大概是这样的：

![[笔记同步助手/images/b705f433cb03332762a199bc1f2d5f0f_MD5.png]]

每次上传笔记时，插件先查一下历史记录：这标题我以前传过没有？

◆ **如果没传过** → 正常流程，新建飞书文档，保存记录。

◆ **如果传过了** → 走增量更新流程。

当你再次上传《项目管理心得》时，插件的执行流程是这样的：

### 1、第一步：查历史

在 uploadHistory 里按标题匹配到上次上传的记录，拿到已有的飞书文档 ID 和链接。

### 2、第二步：更新内容

把 Markdown 笔记的最新内容（去除 YAML frontmatter 后），更新到已有的飞书文档里。

### 3、第三步：更新记录

刷新上传历史里的时间戳，但**文档链接保持不变**。

最终效果是：你改完笔记再次上传，飞书文档内容更新了，但链接还是原来的那个。

发给同事的链接永远是那个，自动看到最新版本。

如果需要这个改进版的obshare插件，你可以找我们获取。

领取后，将文件解压缩保存在你的Obsidian插件目录下即可。

![[笔记同步助手/images/62e28bf1c59c12974ae08cfc510dac63_MD5.png]]

从此，你的 Obsidian 笔记和飞书文档之间，只隔一次点击。

你写笔记时再也不用想着这内容以后怎么分享——**你只管写，分享这件事，交给插件。**
