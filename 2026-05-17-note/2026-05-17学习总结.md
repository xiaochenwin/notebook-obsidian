## 🎯 核心学习主题

### 一、Zotero 与 Obsidian 联动方案 ⭐⭐⭐⭐⭐

**重要程度**: 最高 — 这是今天学习的核心主线

#### 1.1 原生联动方法（最简单，推荐新手）

学习来源: Zotero 与 Obsidian 联动教程：简单高效的阅读与知识管理方案

- **核心操作**: Ctrl+C/V 复制粘贴 + Ctrl+Shift+V 带链接粘贴
- **支持格式**: PDF、EPUB、网页快照
- **Obsidian载体**: 文本、白板(Whiteboard)、画板(Excalidraw)
- **关键技巧**:
  - 拖拽到白板时按 Shift 可带深度链接
  - 网页快照需用 Ctrl+Shift+V 才能保留链接
  - 推荐将资料管理(Zotero)与知识管理(Obsidian)分离

#### 1.2 插件联动方案

学习来源: 科研｜终于实现了Zotero+Obsidian的联动！！、联动obsidian和zotero的无痛方案

**推荐插件组合**:
```
Zotero端: Better Bibtex for Zotero
Obsidian端: Zotero Integration
界面模版: sheldonxxd (obsidian_vault_template_for_graduate_student)
```

**常见问题解决方案**:
- zotero和obsidian设置成onedrive共享后无法创建笔记 → 可能是mdnotes和better bibtex插件冲突
- BibTeX只有调试日志 → 需用better bibtex重新添加文献关键词

#### 1.3 MCP工具方案（进阶）

学习来源: 3天——我终于做出了个MCP工具实现zotero与Obsidian双向联动

**Obsidian Vault MCP** 核心功能:
- 文件操作: 列出、搜索、读取、写入Markdown
- 知识图谱: 自动添加wikilinks、检测死链/孤立笔记
- 文献管理: 深度集成Zotero API，支持BibTeX导入
- PDF解析: 调用MinerU解析PDF并导入Obsidian
- LLM Wiki工作流: 刷新index.md、log.md，整理source/entity/concept页面

**安装提示词**:
```
Install and configure the open-source Obsidian Vault MCP plugin from
https://github.com/luffysolution-svg/obsidian-vault-mcp.
```

#### 5.2 Zotero + Claude + NotebookLM 协同实践

学习来源: 构建高效学术工作流：Zotero + Claude + NotebookLM 协同实践

**三阶段学术工作流**:

| 阶段 | 工具 | 核心价值 |
|------|------|----------|
| 输入 | Zotero | 资料存储与检索、标签多维分类 |
| 处理 | NotebookLM | 信息提取、横向对比、知识图谱构建 |
| 输出 | Claude | 表达优化、框架搭建、降低起笔难度 |

**关键洞察**:
- Notion LM 不是替你读，是帮你**梳理逻辑**
- Claude 不替代判断，是**表达辅助**
- 核心是把"输入→处理→输出"拆开，让精力留给真正重要的思考

### 六、Obsidian 多端同步方案 ⭐⭐⭐⭐

学习来源: 零成本实现 Obsidian 多端同步：小白也能上手的完整指南、Obsidian+AI知识库管理第一步-0成本多端同步

**最终方案**: Remote Save + OneDrive

**避坑要点**:
1. ❌ Google Drive插件: 网络要求高，Token易清空
2. ❌ 坚果云: 免费版限流，大量上传必触发
3. ✅ Remote Save + OneDrive: 稳定可靠，5GB免费空间

**关键设置**:
- 并行度: 默认5 → 改1~2，避免卡死
- 仓库名称: 每端必须完全一致
- 同步方向: Windows双向，Mac/手机增量推送
- ❌ 不要开启"同步配置文件夹"
