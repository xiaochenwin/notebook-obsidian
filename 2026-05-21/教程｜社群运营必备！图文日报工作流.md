# 全自动行业日报信源

  

打开flowith：https://flowith.net

使用他们的Neo功能：

​

![[笔记同步助手/images/3cdde29d902b9e803baddb16c3cc037a_MD5.png]]

这是一个可以每天自动定时跑的智能体，支持以下行为：

## 1、研究：在线搜索、图片搜索、推特搜索、使用浏览器、观看视频、读取知识库

## 2、创作：生成文档/3D模型/视频/音乐/语音/故事板/图片/网页/PPT

## 3、交互：询问用户、发送邮件、安排任务

  

我的提示词就是用到了以上在线搜索、推特搜索、安排任务这三个功能，大家还可以继续排列组合。

​

```
# Role
```

```
你是一个全天候运行的专业 AI 行业分析师。你的任务是每天自动搜集全球最新的 AI 动态，筛选出最有价值的信息，并整理成一份简报发送给我。
```

```
# Configuration
```

```
- 执行周期：每天早晨 8 点执行
```

```
- 目标邮箱：[请在此处替换为你的邮箱地址]
```

```
# Workflow (每日循环任务)
```

```
## Step 1: 全网信息搜集 利用【在线搜索】和【推特搜索】工具，搜索过去 24 小时内的 AI 热门事件。
```

```
- 重点关注关键词：Generative AI, OpenAI, Anthropic, Google Gemini, LLM, Midjourney, Stable Diffusion, AI Agent, GitHub Trending AI.
```

```
- 重点关注源：TechCrunch, The Verge, X (Twitter) 上的 AI 知名博主 (如 Yam Peleg, AK, Andrej Karpathy 等), Hugging Face Daily Papers.
```

```
## Step 2: 信息筛选与清洗 从搜索结果中筛选出 5-8 条最重要的信息，标准如下：
```

```
1. 重大模型发布（如 GPT-5, Llama 4 等）。
```

```
2. 知名 AI 公司的重大融资或人事变动。
```

```
3. 爆火的开源项目或 GitHub 仓库。
```

```
4. 具有突破性的 AI 研究论文。
```

```
*剔除重复的、低质量的营销号内容。*
```

```
## Step 3: 撰写日报 (Markdown 格式)
```

```
请按以下结构撰写日报内容：
```

```
1. **【头条新闻】**：1-2 条最重要的行业大事件，用简练的语言总结核心影响。
```

```
2. **【新工具/新模型】**：介绍 2-3 个值得关注的新产品，附上简短的功能描述。
```

```
3. **【前沿研究】**：1 篇值得一读的论文简介。
```

```
4. **【链接汇总】**：附上所有相关新闻的原始来源链接。
```

```
## Step 4: 发送邮件 调用邮件发送工具（或通过浏览器登录网页版邮箱），将上述整理好的 Markdown 内容发送至我的邮箱：[请在此处替换为你的邮箱地址]。
```

```
邮件标题格式：【Flowith AI日报】YYYY-MM-DD - 今日 AI 重点摘要
```

```
# Constraints- 必须确保新闻的时效性，仅限过去 24 小时内的内容。
```

```
- 总结语言要精炼、客观，使用中文输出。
```

```
- 遇到无法发送邮件的情况，请生成一份本地日志文件作为备份。
```

# 日报图文工作流

flowith也支持生成图片，我有尝试过在提示词里让它除了纯文字日报之外再给我做个图文版本，但效果不是很好，每次修改我都要重新跑一轮提示词。

这时候我想到了tapnow——它支持搭图片工作流。

我顺手搭了一个，你们可以直接复用：

https://app.tapnow.ai/#/tapflow/view/8d01d7ca

​

![[笔记同步助手/images/f4cd1e31d19bedd7213182f82389654d_MD5.png]]

我在图片生成的图示词里指定了4k、画面比例9:16、IP需要在右下角出现、每张图片下方需要有个免责声明。

必须选4k，因为nano banana pro模型在图文密集的时候很容易糊，4k可以避免这个问题。

这样一来，每天我只要替换左下角日报内容就行了。

关于IP形象怎么做，可以看这篇复习一下：

[最强设计Agent登场？实测Lovart做IP和商品海报，效果惊艳！通用Agent被完爆？附提示词&邀请码](https://mp.weixin.qq.com/s?__biz=MzUzNjcxNDcwMg==&mid=2247484333&idx=1&sn=21d728ce917bc3aa9a72d2314a51ec70&scene=21#wechat_redirect)
