## 一、整个流程其实就 3 步

如果你只想看核心,这一章足够:

1.  **写文案**
    
    — 60-90 秒的口播内容,普通文档/备忘录里写都行
    
2.  **打开 Codex,装 HyperFrames**
    
    — 在插件下拉里点加号,搜 hyperframes 安装
    
3.  **在对话框 @hyperframes,丢入文案**
    
    — 一句话:"帮我把这段文字做成一条视频"
    

完事。Codex 会自动:

-   理解你的文案
    
-   拆成适合视频表达的镜头
    
-   决定哪里用动画,哪里用真实感图片,哪里用录屏
    
-   调用 GPT image-2 生成图片(比如喝咖啡的美女、冲浪的帅哥),让画面不腻
    
-   HyperFrames 把标题、字幕、图片、录屏、转场全部组织起来
    
-   全 AI 配音(也可以自己丢配音文件)
    
-   渲染成 MP4

## 二、Codex 在背后到底做了什么

很多 AI 视频工具的痛点是"画面腻"——动画风格反复用,看十秒就够了。

Codex + HyperFrames 是怎么解决的?

**它会自己判断节奏**:

-   **概念表达**
    
    → 用动画 / 图形 / 字幕(信息密度高)
    
-   **氛围烘托**
    
    → 调用 **GPT image-2** 生成真实感图片,画面立刻就不一样了
    
-   **教程演示**
    
    → 用你提供的录屏(可选)
    
-   **节奏切换**
    
    → HyperFrames 把以上全部按节奏组合,加转场
    

你得到的不是几个素材的简单拼接,**而是一条有节奏、有画面、有配音的完整视频**。

## 三、从 0 到 1 完整操作(每一步都给你拆到底)

### Step 1:下载 Codex 桌面 App

## 1.1 打开下载页

浏览器进入 OpenAI 官方下载页:

👉 **https://chatgpt.com/zh-Hans-CN/codex/get-started/**

![[笔记同步助手/images/467c99a4ffe260e9cf20396eb256adc3_MD5.png]]

## 1.2 按系统下载

-   **Mac 用户**
    
    :点 "Download for Mac",下载一个 .dmg 文件(大概 200-300MB)
    
-   **Windows 用户**
    
    :点 "Download for Windows",下载 .exe 文件
    

## 1.3 安装

-   **Mac**
    
    :双击 .dmg,把 Codex 图标(浅蓝色的"终端"样图标)拖到右侧的"应用程序"文件夹
    
-   **Windows**
    
    :双击 .exe,一路点"下一步"安装
    

## 1.4 第一次打开

打开"应用程序"文件夹,双击 Codex 启动。

​

> ⚠️ Mac 第一次打开可能会弹"是否打开来自互联网的应用",点 **打开** 即可。

启动后会看到一个**干净的对话界面**——左侧是历史对话列表,中间是当前对话窗口,底部是输入框。

![[笔记同步助手/images/c378cc13e077812a7c0eb7c3698b8cf0_MD5.png]]

### Step 2:登录 ChatGPT 账号

## 2.1 选择登录方式

第一次打开会弹出登录页,有两个选项:

-   **Sign in with ChatGPT**
    
    (推荐) — 用 ChatGPT Plus/Pro 账号
    
-   **Use API Key**
    
    — 用 OpenAI API key
    

## 2.2 浏览器授权

点 **Sign in with ChatGPT**,浏览器会自动打开 OpenAI 的授权页。

输入你的 ChatGPT 邮箱密码,**点"Authorize"授权 Codex**。

授权成功后,浏览器会显示"You can return to Codex now",回到 App 就能看到你的头像 + 邮箱已登录。

​

> 💡 没有 Plus 也能用 API key,但每次调用都按 token 收费,新手强烈推荐 Plus 流程(月费 $20 用到吐)。

### Step 3:装 HyperFrames 插件

## 3.1 找到插件下拉

在 Codex 主界面,**输入框左侧或上方**会有一个**插件下拉**按钮。

## 3.2 点 + 加号

打开插件下拉后,你会看到已装插件列表(刚装好的 App 这里是空的)。

点列表上方或下方的 **\+ 加号**,进入插件市场。

## 3.3 搜 hyperframes

插件市场的搜索框里输入 **hyperframes**,会出来一个候选(图标是 HeyGen 的 logo)。

## 3.4 点 Install / 安装

点 **Install**,等几秒到十几秒,会显示已安装。

![[笔记同步助手/images/52e4d65372f6d7728ae9e118865d8efe_MD5.png]]

它会装一组配套技能:hyperframes / hyperframes-cli / gsap / tailwind / hyperframes-media(媒体处理:配音、转录、抠图等)——这些会一起装上,不用你管。

## 3.5 验证安装成功

回到主对话界面,**在输入框里输入 @**,如果看到候选列表里有 hyperframes,就说明装好了。

​

> ⚠️ 装完之后,**退出 Codex App 重新打开一次**,让插件完全生效。

![[笔记同步助手/images/2f24784e6c25456ed56f87726baa3f36_MD5.png]]

### Step 4:写文案

## 4.1 选个写文案的地方

随便挑一个你顺手的语音软件:

-   **讯飞听见**
-   **Get笔记**

不想自己写文案的人，就把自己的思考、想法、总结等等所有想表达的东西「自言自语」地记录下来。

然后把这些音频转成文字稿，丢给AI，用下面一段提示词：

​

```
角色定位
你是一个擅长做个人IP内容的内容策划助手。
我会给你一段“我的晨间思考/复盘/观点记录”，这些内容可能是碎片化的、口语化的、逻辑不完整的。
你的任务不是简单润色，而是：
提炼核心观点
找到最适合传播的主题
分别输出：
一篇公众号文章
一条短视频口播文案
注意：公众号和短视频不是同一种表达方式。
输出要求一：公众号文章
目标：帮助读者建立认知、产生共鸣、增强对作者的信任感。
要求：
标题要有传播感不要太官方。要像真实个人IP会写的标题。
开头要有钩子可以是：
一个反认知观点
一个真实感受
一个行业现象
一个问题
目标是让读者愿意继续看。
正文不要只是复述原文而是：
提炼逻辑
增加层次
增加案例感
增加情绪推进
保留“真人感”不要写成AI味很重的鸡汤文章。允许有思考、犹豫、真实表达。
结尾要有观点升华让读者感觉：“这个人是真的在实践和思考。”
文章长度：1500～3000字。
输出要求二：短视频口播文案
目标：做成30～90秒的短视频口播。
要求：
开头3秒必须强钩子比如：
“我发现很多人根本没意识到……”
“AI现在最恐怖的，不是生成内容……”
“做个人IP的人，接下来会被AI重新洗牌。”
全程口语化像真人说话。不要书面表达。
节奏感强短句优先。不要长段落。
要有画面感文案里要自然出现：
操作动作
场景
对比
情绪变化
结尾要有互动感比如：
“你觉得呢？”
“这件事你怎么看？”
“你会这样做吗？”
长度控制：300～500字。
额外要求
不要空话套话
不要鸡汤
不要强行拔高
要保留真实创业者/个人IP创作者的表达感
如果原始内容里有很强的观点，要放大它
如果原始内容比较碎，请主动帮我重组逻辑
我的原始内容如下：
（把你的晨间思考稿放这里）
```

## 4.4 文案结构参考

照着这个结构写更容易出爆款:

1.  **第 1 句:钩子**
    
    (让人想看下去) — 比如"Codex 真的是做个人 IP 的效率天花板"
    
2.  **第 2-3 句:背景反差**
    
    — "以前剪一条视频要 6 小时,现在 3 分钟"
    
3.  **第 4-N 句:具体方法**
    
    — 一步步讲清楚怎么做
    
4.  **最后 1-2 句:行动召唤**
    
    — "如果你也想试,评论区告诉我"
    

### Step 5:在对话框 @hyperframes 发提示词

## 5.1 新建对话

在 Codex App 左上角点 **\+ New Chat**(或快捷键 ⌘N),新建一个干净的对话。

![[笔记同步助手/images/0855c39245414c58c5668ae1f11d0299_MD5.png]]

## 5.2 输入 @ 选 hyperframes

在底部输入框,先打一个 **@** 字符——会弹出候选列表。

用键盘 ↑↓ 或鼠标选 **hyperframes**,按回车确认——你会看到输入框里出现一个 @hyperframes 的高亮标签。

## 5.3 粘贴完整提示词模板

继续在输入框里,粘贴下面这段(**替换 \[...\] 里的内容**):

```
@hyperframes 帮我把下面这段文字做成一条 9:16 中文短视频:

【文案】
[把你 Step 4 写的文案完整粘贴在这里,保留分段]

【风格】(可选,但写了画风会更稳)
深色科技感 / 暖色文艺感 / 简约商务感……
配色:[自定义十六进制色码,可不写]
你也可以参考一些视频示范的风格

【字幕】
中文逐字 karaoke 同步(跟着读),不要段内平均分配时间,
请用 word-level 时间戳让节奏对得上。

【配音】
配音用 AI 全自动生成。声音偏 [清亮女声 / 沉稳男声 / 知性中性] 都行。
(如果你想自己提供配音:把 MP3 也丢到对话里,告诉它"用我提供的 narration.mp3")

【镜头建议】
- 概念表达用动画
- 氛围烘托可以调用 GPT image-2 生真实感图片,避免画面腻
- 如果我有录屏附在对话里,请插入到对应位置

【其他】
- 所有要做动画的元素显式加 id,不要只用 class
- 输出 MP4 到桌面,文件名带日期
```

## 5.4 点发送(或按 ⌘+Enter)

发出去之后,Codex 开始干活。**前 10-30 秒它会先告诉你它的计划**(比如"我准备把这段文案拆成 6 个镜头,分别是……"),你可以看看计划合不合理,不合理就在下面追问"第 3 个镜头我想用真人图片,不要动画"——它会调整后再开始。

也可以把不满意的画面，直接截图，在画面上标注要修改的地方，它就会按照你的要求去帮你修改。

![[笔记同步助手/images/c9425d37ba689b71164fa5203e2ac2ab_MD5.png]]

### Step 6:等 Codex 出片 + 在线追问微调

## 6.1 看进度

Codex 会在对话框里**实时显示**它做了什么:

-   📖 读取文案
    
-   🎨 设计镜头(每个镜头时长、内容、动效)
    
-   🖼️ 调用 GPT image-2 生图(几张图分别花 3-10 秒)
    
-   🎤 生成配音(一般 30-60 秒)
    
-   ✍️ 写视频代码(500-600 行 HTML/CSS/JS)
    
-   ✅ 自动检查 / 修错(如果有错会自己改 1-3 轮)
    
-   🎬 渲染成 MP4(10-30 秒)
    

## 6.2 总耗时

-   **简单视频**
    
    (纯文案 + 全 AI):**3-8 分钟**
    
-   **复杂视频**
    
    (带多段录屏 + 多张生图):**8-15 分钟**
    

## 6.3 完成提示

完成后,Codex 会在对话框给你一条消息:

​

> "视频已完成,保存到桌面:my-video-2026-05-14.mp4(38秒,18.5MB)"

双击打开预览。

## 四、2 个真实踩坑,提前帮你避掉

### 坑 1:中文字幕节奏对不上

默认的"段内字数平均分配"做出来的字幕,**跟着读会错位**——TTS 念字有快慢,平均分配根本不准。

**解决方案:** 在提示词里明确写:**"中文逐字 karaoke 同步(跟着读),用 word-level 时间戳,不要段内平均分配。"** Codex 会调用 HyperFrames 的字级转录能力,节奏一下就稳了。

​

### 坑 2:GSAP 动画静默消失

有时候你会发现生成的视频里少了某些动画,画面也没报错——这是 GSAP 选择器对不上元素的常见问题。

**解决方案:** 在提示词最后加一句:**"所有要做动画的元素都显式加 id 属性,不要只用 class。"** 这样 Codex 出的代码就稳了。

## 五、特别说在前面:第一条做不好,别慌

写这一节是因为我太知道一个事实——**你的第一条视频大概率不会一次到位**。

可能是:

-   节奏太快 / 太慢
    
-   配色不是你想要的
    
-   字幕错位
    
-   某个镜头特别尬
    
-   跑到一半 Codex 报错
    

**这不是 Codex 不行,是任何 AI 都这样。**

AI 学的是**通用能力**——它学过几千万人怎么做视频,但它**还不知道你**:你的语气、你的审美、你的目标受众、你不喜欢什么。

**通用能力变成个人定制能力,中间必须经过"调教"环节。**

这个调教,具体长这样:

-   **第一条**
    
    :你写了模糊的提示词,Codex 出了一个普通版本
    
-   你皱眉:"配色不对、节奏太快、那张图太丑"
    
-   你在对话框继续追问改进
    
-   改了 3-5 次,出来一个还不错的成品
    
-   你**把这次成功的提示词存下来,变成自己的模板**
    
-   **第二条**
    
    :用同一套模板,只换文案,效果就稳了
    
-   **第三条**
    
    :你越来越知道什么样的描述能让 Codex 一次出对
    
-   ……
    

**这些"花时间调教"的时间,绝对值得。**

为什么?因为:

-   ❌ **传统剪辑**——你需要**永远花同样的时间**,每条视频都是 4-6 小时
    
-   ✅ **AI 调教**——一次性投入,复利收益。今天多花 2 小时把第一条调好,**之后每条都省 5 小时**
    

**一旦掌握了方法,后面用 AI 越来越顺,做出来的产品也会越来越好。**

不要被第一条挡住。它本来就是用来**教 Codex 认识你**的。

## 六、真正的价值:从第二条视频开始

如果你光做一条视频,这套流程的收益并不夸张——下载 App、装插件、调教提示词,第一条多少要花点时间。

**但从第二条开始,情况完全不一样。**

你不用每次:

-   ❌ 重新想视频结构
    
-   ❌ 重新找配图素材
    
-   ❌ 重新剪辑节奏
    
-   ❌ 重新调整字幕和转场
    
-   ❌ 重新对配音时间
    

你只要做一件事:

✅ **把表达讲清楚,扔给 Codex**

剩下的全部交给流程。

我做第二条视频用时 10 分钟,做第三条 8 分钟,做第四条已经只是粘文案 + 喝口水。**这套流程的复利,从第二条开始才真正显现。**

## 七、写在最后:做个人 IP 的人,终于可以只做内容了

很多人觉得做视频的门槛在剪辑——其实**真正卡你的是重复劳动**:对字幕、调动效、改时间轴、改完字幕又错位……

Codex App + HyperFrames 把这部分**全自动化**了。你的精力可以全花在**只有你能做的事**上:写脚本、定调性、想选题。

如果你正在做个人 IP,正在被剪辑拖累,这套工作流值得你这周末就花 1-2 小时装一遍。

第一次跑通的那一刻,你会真切感受到——**我们做内容的人,终于可以只做内容了**。
