## 前言：为什么选择Claude Code？

本文将手把手指导您在无代理、无Claude账号的情况下完成Claude Code的安装。整个过程无需任何编程基础，适合零技术背景的用户。作者作为非程序员的产品经理，已持续使用Claude Code超过一年，每日应用于实际工作场景。

首先解答几个常见疑问：

-   **Claude Code与“小龙虾”是同一类产品吗？** 两者均为顶尖AI工具，但路线不同。“小龙虾”侧重广度，集成于聊天软件中，支持跨平台消息处理；而Claude Code专注深度任务，具备强大的规划能力与上下文管理机制，擅长从零开始完成复杂项目，如行业调研、内部工具开发和广告物料生成等。
-   **是否真的适合非技术人员？** 是的。作者以零技术背景身份，曾用一周完成的行业报告现在只需十分钟；原本需排期开发的内部投票工具，现可自行半小时内构建完成；甚至搭建了一套自动化广告物料生产流程，单日可产出十余组素材。
-   **没有海外账号还有必要安装吗？** 非常有必要。市面上多数AI编程工具本质是“辅助写代码”，要求用户具备一定技术能力；而Claude Code的目标是“自主完成编码”，全程无需手动干预，真正实现零代码操作。

## 安装准备：系统与环境

本教程以macOS系统为例进行演示，Windows用户的安装逻辑一致，仅命令略有差异。关键步骤截图将附于文末供参考。

### 第一步：安装Homebrew（macOS）

Homebrew是macOS上的软件包管理工具，用于简化后续安装流程。

打开终端，执行以下命令：

`/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`

输入系统密码后按回车确认。安装完成后，根据提示执行路径配置命令，确保Homebrew可用。

验证安装是否成功：

`brew --version`

若显示版本号，则表示Homebrew已成功安装。

![[笔记同步助手/images/784b634ca3e8ab505170a28d7e445fd8_MD5.jpg|终端中显示brew --version命令输出Homebrew版本信息]]

终端中显示brew --version命令输出Homebrew版本信息

### 第二步：安装Claude Code

通过Homebrew安装Claude Code主程序：

`brew install claude-code`

当出现“successfully installed”提示时，说明安装成功。

验证安装：

`claude --version`

若显示版本号（如2.1.143），则表示安装成功。此时运行`claude`命令，看到橙色小螃蟹标志，说明程序可启动，但尚未接入AI模型，仅为本地壳程序。

![[笔记同步助手/images/b22a7deb8d1a2a514da2b97ca2266e7c_MD5.jpg|终端中运行claude命令后显示橙色小螃蟹图标]]

终端中运行claude命令后显示橙色小螃蟹图标

### 第三步：安装CC Switch（模型管理工具）

CC Switch是一款国产AI模型管理工具，支持一键切换多种本地或云端模型，避免手动修改配置文件。

在终端中执行安装命令：

`npm install -g cc-switch`

安装完成后提示“cc-switch successfully installed”，即表示模型管理器已就绪。

### 第四步：获取API密钥并配置模型

本教程选用小米MIMO模型，因其性价比高且效果稳定。用户也可替换为其他国产模型，如DeepSeek、Kimi、MiniMax等。

在浏览器中搜索“小米API”，登录后获取API Key与Base URL。若订阅了月度套餐，需注意使用对应的专属接口地址。

启动CC Switch，点击右上角“+”号，选择“自定义配置”，填写以下信息：

-   API Key：填入从小米平台获取的密钥
-   Base URL：粘贴兼容OpenAI协议的接口地址

保存后点击“获取模型列表”，在下拉选项中选择“mimo-2.5-pro”作为默认模型，并启用该配置。

![[笔记同步助手/images/9a6fcfa2534aaf7fdef71c76b37663c6_MD5.jpg|CC Switch界面中添加小米MIMO模型配置，包含API Key和Base URL输入框]]

CC Switch界面中添加小米MIMO模型配置，包含API Key和Base URL输入框

### 第五步：启动Claude Code并测试对话

返回终端，输入`claude`命令启动程序。

首次运行会提示安全警告，按回车继续；选择推荐设置，并确认信任当前项目目录。

若界面中出现“mimo-v2.5-pro”模型名称，即可开始对话测试。尝试输入简单指令，如“写一个欢迎页面”，观察响应结果。

成功生成HTML文件后，可本地打开查看效果，确认AI已完整实现前端代码编写。

![[笔记同步助手/images/69031d711a9a3ed6b3168abc3183593b_MD5.jpg|Claude Code生成HTML代码并在浏览器中展示网页效果]]

Claude Code生成HTML代码并在浏览器中展示网页效果

## 结语：跨平台兼容与后续内容预告

Windows用户安装流程与macOS基本一致，仅第一步需使用WinGet替代Homebrew：

1.  通过WinGet安装Git
2.  通过WinGet安装Claude Code
3.  后续步骤完全相同

安装完成后，建议进行基础设置，包括模式选择（如规划模式、简洁模式）与预算控制（bill体系），这些将在后续视频中详细介绍。
