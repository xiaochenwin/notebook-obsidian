目前，自主科研 Agent 已经能够跑通“从灵感到论文”的完整流程。研究者一觉醒来，AI Agent 也许已经跑完实验、甚至能够写出一篇有模有样的论文。  
  
听起来很美好，但我们怎么知道，AI 有没有在结论里悄悄“说谎”？  
  
目前，Agent 仍存在两个关键问题，一是生成和审查常常由同一模型家族完成，许多系统性错误因此难以在内部暴露；其二，当一个 Agent 在几乎无人监督的情况下连续工作数天后，其最终给出的结论往往难以判断是否真的有充分证据支撑。  
  
针对这些问题，上海交通大学团队提出了“在睡眠中自动研究”（Auto-Research-in-sleep，ARIS），一个用于自动化科研的开源研究 harness。  
  
这项工作的重点，不是让 Agent AI 更快写出论文，而是让 AI 写出的论文更经得起检验。  
  
值得一提的是，在社区实操案例展示中，已有研究人员使用 ARIS 全流程完成了各自论文，并被会议接受。#大模型 #AI #agent #论文 #科研学习 #人工智能 #上海交通大学 #智能体
