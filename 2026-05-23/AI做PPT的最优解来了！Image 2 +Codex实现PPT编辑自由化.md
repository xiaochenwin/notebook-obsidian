```
GPT Image 2 指令：请根据主题为“介绍Image2”的内容，为我设计一套PPT页面，以完整的单页图片形式输出。要求：基础规范：PPT比例为9:16，页数不固定，完全根据内容体量适配，覆盖所有核心模块，不凑数也不遗漏关键信息。风格要求：极简、高级、文本信息层清晰，排版精简，留白呼吸感，配色统一，不出现复杂的构图。要有封面页和总结页。有专业的文本信息和内容。画面以结构化图形、数据可视化元素、色块、板式框架为主，搭配辅助文字，形成完整的视觉系统。输出为完整的单页PPT页面。
```

第2步：在Codex转化为完整PPT文件

![[笔记同步助手/images/8920effad37625a5d40fc7d303bff1f2_MD5.png]]

```
Codex 指令：将这10张图片做成PPT
```

第3步：在Codex拆分所有元素为单独PNG

![[笔记同步助手/images/e3824067471634a53926c32630b5c5e5_MD5.png]]

```
Codex 指令：请将刚才生成的PPT进行拆分处理：要求：将每一页的所有视觉元素拆分为单独的PNG图像包括：每一个元素单独一张PNG。保持所有元素的原始相对位置不要移动或者改变比例。每个PNG不要有背景不要合并元素，每个素材单独输出不需要任何文字内容如果一次性无法全部生成，请批量输出，直到所有页面元素拆分完成，直接输出出来图片，不要文件夹。
```

![[笔记同步助手/images/8a525476acb0f7ec58066f586cd182fa_MD5.png]]

```
Codex 指令：请使用上一步拆分得到的所有PNG素材，还原并制作一套完整的可编辑的PPT文件要求：布局还原：按照上一步原始PPT页面的完整布局，将所有PNG素材移动到对应的位置，还原所有页面的版式框架（含全部适配页数）文本处理：在还原的板式中，加入可编辑文本框，所有后续新增文字为独立可编辑内容，禁止把文字做成图片格式。格式输出为整体输出为标准的PPT格式文件，可直接修改文字、替换数据、调整布局的，可直接用于正式汇报的PPT。
```

优势： 将视觉元素彻底拆散再重组，编辑颗粒度最细， 适合对版式还原度和文本可控性 有极高要求的专业场景。
