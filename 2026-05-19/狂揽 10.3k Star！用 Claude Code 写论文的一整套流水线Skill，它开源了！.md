上周一个研究生的朋友发我消息："我的 lit review 堆了三个月了，引用核对就能搞死我，根本没时间想有趣的东西。"

项目的自我定位很有意思——官方 README 开头第一句话是：

> **AI is your copilot, not the pilot.** This tool won't write your paper for you.

这句话我觉得是理解这个项目的钥匙。它不是那种"你输入一个题目，它吐出一篇论文"的自动化工具。它的设计逻辑更像是**帮你把脑力从机械劳动中解放出来，专注在真正值钱的部分**。

## 4 大技能 + 25 种模式，到底能干什么

整个项目分成 4 个技能模块，合计 25 种运行模式。我逐个拆一下。

---

### 🔍 deep-research：7 种模式的文献与研究分析

这是我觉得日常用频率最高的模块。

| 模式 | 干嘛的 |
| --- | --- |
| `full` | 完整学术研究报告，3000-8000 字，APA 7.0 格式 |
| `quick` | 30 分钟快速研究简报，500-1500 字 |
| `socratic` | **苏格拉底对话模式**，帮你把模糊的想法磨出清晰的研究问题 |
| `lit-review` | 注释式文献综述 + 综合分析 |
| `fact-check` | 逐条论点核实，验证你引用的证据是否真的支持你的说法 |
| `systematic-review` | PRISMA 2020 格式的系统综述，5000-15000 字 |
| `review` | 对某篇具体文献的评估报告 |

特别值得说的是 `socratic` 模式——如果你有个想法但不知道怎么定框架，直接告诉 Claude "我对 XX 话题有模糊的兴趣，帮我想清楚"，它会通过 5-15 轮对话，把你的直觉打磨成一个可执行的研究问题。这对研一研二的同学来说太有用了。

---

### 📝 academic-paper：10 种模式的论文写作

这是功能最密集的模块，10 种模式基本覆盖了论文生命周期的各个节点：

```
"Write a paper on X"                         → full mode（完整论文草稿）
"Guide me through writing a paper"           → plan mode（逐章苏格拉底引导）
"Build a paper outline"                      → outline-only mode
"I have a draft, here are reviewer comments" → revision mode（整合审稿意见）
"Parse these reviewer comments"              → revision-coach mode（修改路线图）
"Write an abstract"                          → abstract-only mode
"Generate an AI disclosure for NeurIPS"      → disclosure mode（生成 AI 使用声明）
```

其中 `disclosure` 模式我觉得挺超前的——现在越来越多期刊和会议要求附上 AI 工具使用声明，这个模式能帮你生成符合特定期刊政策的 AI 使用声明，省去一堆格式折腾。

输出格式支持 MD + DOCX（通过 Pandoc）+ LaTeX（APA 7.0 / IEEE / Chicago），可以直接生成 PDF。

---

### 🎓 academic-paper-reviewer：6 种模式的论文审稿

这一块我觉得是整个项目里最有意思的部分。

`full` 模式会输出：**5 份不同视角的审稿报告 + 主编决定 + 修改路线图**。

也就是说，在你投稿之前，你能提前看到你的论文在多个"模拟审稿人"眼里是什么样的。更细的，还有 `calibration` 模式——它会给出审稿人的准确性校准报告（FNR/FPR/AUC 指标），让你知道哪些审稿意见更可信、哪些可能是误判。

`guided` 模式是逐问题苏格拉底引导，不是直接给你改好，而是带你一步步想清楚每个问题怎么解决。

---

### ⚙️ academic-pipeline：10 阶段全流程编排

如果上面三个模块是"单兵作战"，`academic-pipeline` 就是"集团军"——把 research → write → review → revise → finalize 整个流程串成一个 10 阶段的自动编排工作流。

官方给出的参考成本：**约 $4-6 API 费用，2-4 小时协作时间**。

还有一个细节：支持从 Passport 断点续跑。如果中途对话上下文满了或者会话中断，可以从检查点恢复，不用从头来。

## 一个我很认同的设计理念

做 AI 工具的，很多都在卷"自动化程度"——我的工具比你自动一点、生成速度更快。

但 ARS 的设计逻辑是反着来的：**所有关键节点都有强制 Checkpoint，用户必须确认才能推进。**

`FULL checkpoint`：所有交付物呈现后，需要明确确认才进入下一阶段。`MANDATORY checkpoint`：在引用核查、审稿意见决策等高风险节点，不可跳过。

官方文档里有一句话说得很直接："Full mode" means full-pipeline execution, not full autonomy — the human decides at every gate.

另外，这个项目有个 `Style Calibration` 功能——会从你过去的论文里学习你的写作风格，所以输出读起来是"你的声音"，不是那种一眼能看出是 AI 写的通用体。

还有 **Writing Quality Check**——专门检测 AI 典型表达模式，目的是让你写得更好，而不是帮你规避 AI 检测工具。这个区别很重要。

## 30 秒安装

需要 Claude Code v3.7.0 及以上版本。

```
# 两行搞定
/plugin marketplace add Imbad0202/academic-research-skills
/plugin install academic-research-skills
```

装完之后，输入 `/ars-plan` 就可以开始用苏格拉底对话规划你的论文结构。

想快速试一下效果？运行：

```
/ars-lit-review "你的研究话题"
```

可选依赖：

​

-   Pandoc：用于生成 DOCX
    
-   tectonic + Source Han Serif TC：用于生成 APA 7.0 PDF
    
-   纯 Markdown 输出不需要任何额外工具

## 适合谁用

坦白说，这个工具对**在读研究生和博士生**的价值最大——因为你有足够的学术判断力来使用这些辅助，又足够被脏活累活困扰。

如果你：

​

-   在做文献综述但被引用核查搞崩了 → `lit-review` + `fact-check`
    
-   有个想法但不知道怎么定研究问题 → `socratic` 模式
    
-   论文初稿写完，想在投稿前预演审稿结果 → `academic-paper-reviewer full`
    
-   收到 Reject + R&R 不知道如何回应 → `revision-coach`
    

……那你可以去试试了。

但如果你的期待是"输入题目，输出论文，直接交差"——这个工具不是这样设计的，也明确反对这样用（CC BY-NC 4.0 许可里明确禁止了商业化部署，项目文档里也明确说这不是自动写论文系统）。
