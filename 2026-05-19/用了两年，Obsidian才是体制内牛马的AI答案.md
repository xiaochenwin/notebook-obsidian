# 用了两年，Obsidian才是体制内牛马的AI答案

## 用了两年，Obsidian才是体制内牛马的AI答案

作为体制内牛马，深度使用 Obsidian 也快两年了。  
截至目前，个人感觉在加速演进的 AI 时代，Obsidian 可能才是体制内牛马们的 AI 答案。

### 🔒 理由一：数据私有化

体制内工作，稳妥第一，也就是数据必须在自己电脑上。  
比如没定稿的材料、内部讨论的要点……这些东西如果我不想绑在任何公司的服务器上，万一下个月工具涨价、关停、被收购，这样的焦虑将会随着系统的愈发庞大而变得愈发激烈。

本地文件 + 纯文本 = 话语权。  
当然，敏感岗位的朋友自己判断边界，我只说技术上的可能性。

### 🧩 理由二：解决信息碎片化

体制内工作还有个特点，就是碎杂，会议纪要、政策要点、待办事项……  
所以我需要一个系统：信息进去了可以自动归类——阅读笔记归阅读库，会议纪要归重要会议库，零碎想法归知识库，而这些能力，有谁能比AI做的更好？

而 Obsidian 的 Markdown 文件，就是最友好的 AI 格式。  
加上今年 Obsidian 官方更新了 CLI，作者还专门写了 Skills，让 AI 可以底层操控笔记库，知识可以真正活起来。

### 🤖 理由三：不只是笔记，而是 AI 团队

Obsidian 演变到今天，它的高度灵活性使得它已经不是一个单纯的笔记工具，而是 AI 的底座。  
比如我现在的系统里，就尝试使用 Hub-and-Spoke 架构，搭建了以下几个 agent。

#### 🧠 参谋长 — 主 agent

直接向我汇报，同时按需调度其他 sub-agent。

#### 💼 工作军师 — Sub agent

负责材料思路、公文辅助、督办跟进。

#### 🔧 系统工程师 — Sub agent

负责记录维护、系统优化、自我迭代。

#### 📱 生活管家 — Sub agent

负责教育建议、旅行规划、日常杂事。

同时在调用方法上，得益于去年底开始的“小龙虾🦞”，已经可以实现电脑和微信两种方式，随时随地和主 agent 联络，记录碎片想法、待办事项等。

说白了，就是以 Obsidian 为第二大脑，接入 Agent 团队，打造属于自己的“数字综合处”。  
可能，这才是 AI 时代该有的工作方式吧。

### 系统使用情况展示

目前使用 Obsidian 已 521 天，共创建了 759 个笔记，520 个标签。  
知识库结构清晰，包含：

-   工作内容库
-   重要会议库
-   重点企业库
-   阅读库
-   知识库
-   重点任务库

通过模板化录入（如“知识录入模板.md”、“产业载体录入”等），实现高效沉淀。  
近期内容录入热力图显示活跃度稳定，知识持续积累。

各库主页功能明确：

-   **阅读库主页**：与微信读书同步，实时展示书库情况。
-   **重要会议库主页**：全量展示会议记录，支持统一筛选、排序，便于管理。
-   **知识库主页**：记录学习笔记、个人思考、新闻动向等内容。

### 实战场景：今天有哪些待办？

看了下待办跟踪，今天（5月14日）最要紧的是这几条：

-   合同签批流程明天截止，今天必须走完流程
-   局征求意见稿回复——先找人当面说想法
-   爸妈体检报告传家庭医生建档——高血脂、高血压需重点关注
-   推进合同签订——已电话联系，让其尽快启动响应流程
-   启动调研报告——5.12已启动，今天有没有推进？

明天还有到期提醒事项，压力不小。其中合同签批和征求意见稿回复两条不能拖，先搞定这两样再说。

通过 iM 工具（微信、QQ、飞书等），将 Agent 与手机绑定，实现随时随地激活主 Agent，调用 sub-agent 获取信息；同时也能通过微信随时录入碎片化思考、待办事项至第二大脑 Obsidian，晚上回家后系统性整理入脑，实现知识复用。

目前这套系统，我也还在不断摸索，也会持续分享系统迭代记录。  
毕竟我自己非技术出身，都是现学的，分享出来大家可以一起讨论，一起进步！
