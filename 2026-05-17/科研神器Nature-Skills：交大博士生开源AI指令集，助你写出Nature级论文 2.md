对于每一位科研工作者而言，从数据整理、图表绘制到论文撰写、返修回复，每一个环节都充满了挑战。为了应对这些挑战，上海交通大学的博士生袁一哲创建并开源了一个名为 **nature-skills** 的项目，这是一套专为学术研究场景设计的、可重用的高质量 AI 指令集（Skills）。

该项目旨在将顶级期刊（如 _Nature_）的写作规范、图表标准和严谨的科研流程，封装成一系列即插即用的 AI “技能”，帮助研究人员极大提升工作效率和产出质量。

**GitHub 项目地址**：

https://github.com/Yuan1z0825/nature-skills

## 项目简介与作者

`nature-skills` 项目由上海交通大学博士生袁一哲主导开发，他目前专注于医疗 AI 相关的研究与创业实践。该项目不仅是一个开源工具库，更是一个活跃的社区。作者欢迎用户通过提交 Issue 来提出功能需求，并鼓励社区成员通过 Pull Request 贡献代码和技能，共同推动项目发展。

## 关键技能详解

### 1\. `nature-figure`: 生成 Nature 级别的科研图表

此技能专注于生成符合 _Nature_ 期刊视觉标准的多面板图表。它能确保正确的字体、语义化的调色板、可编辑的 SVG 格式输出，以及信息架构的合理性。

-   **功能简介**：根据数据和需求，生成专业的 Matplotlib 或 R 语言图表代码。
-   **核心特点**：
    -   **严格规范**：强制使用无衬线字体（如 Arial），并确保输出的 SVG 文件中文字是可编辑的文本节点，而非路径。
    -   **信息层级**：遵循“概览 → 偏差 → 关系”的三层信息结构，避免面板信息冗余。
    -   **丰富图库**：支持条形图、折线图、热图、散点图、雷达图、分布图等 10 种图表类型。
    -   **内置范例**：集成了来自 `figures4papers` 项目的多个已发表论文的图表示例代码。

### 2\. `nature-polishing`: 学术论文语言润色

此技能致力于将您的学术草稿（支持中译英）打磨成符合 _Nature_ 期刊惯例的专业行文。

-   **功能简介**：对文本进行 12 步精细化润色，提升语言质量。
-   **核心规则**：
    -   **句长控制**：确保每句话不超过 30 个单词。
    -   **时态与语气**：根据章节（如“结果”部分用过去时，“讨论”部分使用推测性语气）调整时态和措辞。
    -   **词汇精确**：使用更专业、精准的学术词汇。
    -   **英式英语**：统一使用英式英语拼写（如 `colour`, `analyse`）。
    -   **避免过度声明**：标记绝对化、无根据的因果关系等过度声明的风险。

### 3\. `nature-writing`: 论文章节结构化写作

此技能用于从零开始起草或重构论文的核心章节，重点在于构建强有力的逻辑论证。

-   **功能简介**：根据您提供的论点、结果、图表或草稿，生成摘要、引言、结果、讨论等章节。
-   **核心规则**：
    -   **证据先行**：不允许凭空捏造数据、机制或参考文献。
    -   **经典的“沙漏”结构**：引言部分从宏观领域背景切入，逐步聚焦到具体研究空白；讨论部分则从研究结果出发，逐步拓展其意义和影响。
    -   **逻辑清晰**：“结果”部分应构建一个证据链，而非简单罗列实验流水账。

### 4\. `nature-paper2ppt`: 论文一键生成中文 PPT

对于需要进行组会报告或 Journal Club 的研究者来说，这是一个极其高效的工具。

-   **功能简介**：将一篇科研论文（PDF、文本、摘要均可）快速转换成一份结构清晰的中文 `.pptx` 演示文稿。
-   **核心规则**：
    -   **叙事逻辑**：以论文的科学论证为主线构建幻灯片，而非简单照搬原文章节顺序。
    -   **图表为证**：智能筛选支撑核心论点的关键图表，并进行适当裁剪或拆分以保证清晰度。
    -   **直接可用**：直接生成包含中文标题、要点、注释和演讲者备注的 `.pptx` 文件。

### 5\. `nature-response`: 智能辅助回复审稿意见

返修是论文发表的必经之路，而高质量的回复信（Response Letter）至关重要。

-   **功能简介**：帮助起草、审核和修改逐点回复审稿人意见的信函。
-   **核心规则**：
    -   **完整性**：确保每一条审稿意见都被标记、分类并得到回应。
    -   **行动映射**：将回复与具体修改操作（如 `ACCEPT_TEXT` - 接受文本修改）关联，清晰明了。
    -   **可追溯性**：所有声称的修改都必须明确指向稿件中的具体位置（章节、页码、图表等）。
    -   **语气专业**：使用合作、基于证据的语言，避免与审稿人产生情绪化对立。

## 如何安装和使用

`nature-skills` 的安装方式非常灵活，可以适配多种 AI Agent 工具。

​

#### 1\. Codex 用户

这是最简单的安装方式，直接将技能文件夹复制到 Codex 的技能目录即可。

**克隆仓库**

```
git clone https://github.com/Yuan1z0825/nature-skills.git
cd nature-skills
```

**安装所有技能**

```
mkdir -p ～/.codex/skills
for d in skills/nature-*; do
 cp -R "$d" ～/.codex/skills/
done
```

安装完成后，重启 Codex 即可通过自然语言调用，例如：“Translate this paper into a full markdown reader.” 或 “用中文把这篇论文做成一个 journal-club PPT。”

​

#### 2\. Claude Code 用户

通过插件市场安装，体验无缝。

**添加插件市场（仅需一次）**

```
/plugin marketplace add https://github.com/Yuan1z0825/nature-skills
```

**安装插件**

```
/plugin install nature-skills
```

**重载插件以生效**

```
/reload-plugins
```

重载后，所有技能将自动可用。

​

#### 3\. 其他 Agent 或手动使用

如果您的 AI 工具支持自定义系统提示词或配置文件，只需将相应的 `skills/nature-` 文件夹（包含 `SKILL.md` 和 `references/` 等文件）复制到您的提示词库中，并根据需要调整格式即可。

​

## 项目的设计原则

`nature-skills` 的所有技能都遵循以下共同原则：

1.  **来源权威**：所有规则均基于已发表的 _Nature_ 内容或官方指南，而非个人偏好。
2.  **明确优于隐含**：每条规则都有其背后的原理和解释。
3.  **情境感知**：针对论文的不同部分（如引言、方法、讨论）应用不同的逻辑和规则。
4.  **产出导向**：每个技能都旨在生成可直接使用的最终产出物（如代码、文本、`.pptx` 文件），而非中间规划文档。
5.  **可扩展设计**：每个技能都是独立的，添加新技能不会影响现有技能。

**nature-skills** 是一个极具价值的开源项目，它将顶级学术出版的智慧与 AI 的强大能力相结合，为科研人员提供了一套覆盖研究全流程的“瑞士军刀”。无论您是需要绘制出版级图表、润色论文语言，还是高效准备组会报告，它都能成为您的得力助手。

我们强烈推荐所有科研工作者、学生和学者关注并试用这个项目，并为其发展贡献自己的一份力量。
