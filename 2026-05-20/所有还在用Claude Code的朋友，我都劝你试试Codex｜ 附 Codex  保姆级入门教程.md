大家好，我是库森。

最近有个明显趋势：**很多之前用 Claude Code 的人，开始转向 Codex 了。**

为什么？说白了三个原因：

**第一，Claude Code 封号越来越频繁，Codex 对国内用户友好得多。** 不少人 Claude Code 用着用着号就没了，Codex 目前在这方面宽松很多。

**第二，Codex 最近能力突飞猛进。** 密集更新了一波功能——电脑操控、浏览器操作、自动化任务、插件生态，能力边界一下子拉开了。

**第三，GPT 模型本身变强了。** 很多人印象里 GPT 不如 Claude，但现在 Codex 里的模型在代码、推理、长文本上都有明显提升，实际用下来差距已经很小。

今天Codex 再次更新，能上手机了，直接塞进 ChatGPT App，iOS 安卓同步，免费用户也行。

但问题也来了——很多人下载之后打开一脸懵：左边一堆按钮，右边弹各种面板，不知道从哪开始。

今天这篇，我把 Codex 上手流程拆成 **4 步**，从下载到实战，App 和 CLI 都讲清楚。跟着做，半小时就能玩明白。

​

> 本文基于 Mac 版 Codex App 实测整理。Codex 版本：26.429.61741。Codex App 更新很快，你看到的按钮名称和位置可能会有一点变化，但核心逻辑基本一样。

## 先搞清楚Codex 产品形态

很多人一听 Codex 就懵，因为它其实有**两个东西**：

**Codex App**（桌面应用）：有图形界面，像一个超级版 ChatGPT。能聊天，也能操作电脑、读文件、做文档、连接各种工具。

**Codex CLI**（命令行工具）：在终端里用，没有界面，全靠打字。更轻更快，适合在具体项目里干活。

一句话：**App 是万能助手，CLI 是项目搭档。不冲突，可以同时用。**

想快速体验，从 App 开始就够了。想深度使用、发挥最大生产力，建议 App 和 CLI 都玩起来。

## 一、下载安装 + 账号登录

### 1、🪜（必须）

说个现实的问题：Codex 是 OpenAI 的产品，国内**没有🪜是用不了的**。下载、注册、登录、使用，全程都需要。

如果你还没有🪜，需要自己解决，网上教程很多，这里不展开。

### 2、注册账号

你需要一个 **OpenAI / ChatGPT 账号**。之前用过 ChatGPT 的，直接拿那个号登录就行。

没有的话，去 **chat.openai.com** 注册。注意：**现在注册可能需要海外手机号验证，国内手机号是不行的。** 可以用接码平台，买个海外号接一下验证码就搞定。

### 3、账号怎么选

账号分三档：

-   **免费账号**——能用，但额度很少，体验几下就没了
    
-   **Plus（20 刀/月）**——日常够用，建议至少从这个起步
    
-   **Pro（200 刀/月）**——重度用户才需要，额度拉满
    

**建议先搞个 Plus 体验，觉得离不开了再考虑升 Pro。**

### 4、Codex App 下载安装

Mac 和 Windows 都支持，从 OpenAI 官网下载：**openai.com/codex**

![[笔记同步助手/images/7d066332c67e7ce06c3c7b74166026cd_MD5.png]]

安装过程和普通软件一样：

-   Mac：下载后拖进"应用程序"，打开
    
-   Windows：下载安装包，双击安装，打开
    

打开后会弹出登录页面，用你的 ChatGPT 账号登录就行。**记得全程挂🪜，不然会卡在登录页。**

### 5、Codex CLI 安装

CLI 需要先装 Node.js（18 以上版本），然后一行命令：

​

npm install -g @openai/codex

![[笔记同步助手/images/d68f67e9ed2c26eecc6fd7d21184625a_MD5.png]]

国内网络环境装不上的话，用阿里云镜像：

​

npm install -g @openai/codex --registry=https://registry.npmmirror.com

![[笔记同步助手/images/767ad91935fa01645ec261df0120c862_MD5.png]]

装完在终端输入 `codex` 回车，按提示登录 OpenAI 账号。CLI 登录是通过浏览器跳转授权的，同样需要🪜。

## 二、基本操作

### 1、界面布局：记住三块就够

打开 Codex App，界面分三块：

-   **左边**——导航栏：新对话、项目、插件、自动化、设置，所有入口都在这
    
-   **中间**——对话区：你和 Codex 交流的地方
    
-   **右边**——结果区：Codex 生成的文件、网页预览、代码差异都在这显示
    

![[笔记同步助手/images/974c78f3c885d31105798000d8a2dcb1_MD5.png]]

先知道"**左边找入口、中间说话、右边看结果**"就够了。

### 2、新建会话 vs 新建项目

这两个是最基本的使用入口，很多人第一次就搞混：

**新建会话**：纯聊天，不绑定任何文件夹。适合问问题、写文案、头脑风暴这类不需要读本地文件的任务。

**新建项目**：绑定你电脑上的一个具体文件夹，Codex 可以读取和操作里面的文件。适合需要处理文档、分析数据、写代码等需要动文件的场景。

**新手建议**：先从新建会话开始玩，等需要让 Codex 读你的文件时，再用新建项目。

### 3、权限选择

新建项目时，Codex 会让你选权限等级：

![[笔记同步助手/images/56e88865fc6356c2bb8cb9343d99dbad_MD5.png]]

权限越高，Codex 能自主做的事越多，但风险也越大。**刚开始建议选中间档，操作前会先问你确认。** 等你熟了，再根据需要调高。

## 三、实战：让 Codex 帮你干正事

界面认识完了，直接上实战。光会聊天没意思，Codex 真正强的地方是**帮你做事**。

### 1、写一份 Word 调研报告

这个场景所有人都用得上。比如你想了解新能源汽车行业现状，直接告诉 Codex：

​

```
帮我写一份《2026年新能源汽车行业调研报告》，要求：
1. 自己搜索最新的行业数据
2. 包含市场规模、头部品牌、技术趋势、政策环境
3. 输出为 Word 文档
```

![[笔记同步助手/images/24c9caabd0c47f86f0997d4ee4274024_MD5.png]]

Codex 会自动打开内置浏览器搜索资料，整理数据，最后生成一份排版完整的 Word 文档，几分钟后就生成了 4200 字的word 文档。

整个过程你只需要提需求，剩下它全包了。这活人工来做，搜资料、整理、排版，没个大半天搞不定。  
![[笔记同步助手/images/babed4faf9e82fb291af41999453690f_MD5.png]]  
![[笔记同步助手/images/11ab7accc16d9e2ef68ef54f5fbd2653_MD5.png]]

**说个我自己的经历。** 之前我要申请 B 站开放平台的数据，需要填一份 Word 模板表格。字段多，格式严格，人工填至少半小时。我直接把营业执照图片丢给 Codex，让它帮我对着模板填，几分钟就搞定了。这种重复性的文档工作，交给它是真的香。

### 2、做 PPT

Codex 内置了 Presentations 插件，可以直接生成演示文稿。基础的 PPT 它能搞定，但说实话，**想做出更专业的 PPT，需要配合 Skill 和 MCP 来用，效果会好非常多。** 这个展开讲内容太多了，后面我会单独出一期详细教程，感兴趣的先关注不迷路。

![[笔记同步助手/images/ab36f220fa5f3f874c7522fd587667f2_MD5.png]]

### 3、电脑操控：几个实用又安全的场景

Computer Use 是 Codex 最强的功能之一，说白了就是让 AI 直接操作你电脑上的软件界面——那些没法用命令行搞定的事，它来帮你点。

举个实际场景：让 Codex 帮你在知网搜论文。

​

```
帮我去知网搜索"大模型"相关的论文，筛选最近一年的，按照引用量排序，
把前10篇的标题、作者、摘要整理成一个表格给我
```

操作过程会要些权限  
![[笔记同步助手/images/995707be82e0ab0cbff840efbc75b5e5_MD5.png]]

Codex 会自动打开浏览器，进入知网，输入关键词搜索，设置时间筛选，然后逐篇提取信息整理成表格。这套操作人工来做，光是复制粘贴就得小半个小时。  
codex 只用了 7 分钟就搞定了，这过程完全自己休息，还有很多场景可以探索。  
![[笔记同步助手/images/39773d3820bc9c854dccc6bc0bb360e7_MD5.png]]

![[笔记同步助手/images/077d90ec54af22d0cedd58936f6c432f_MD5.png]]

论文都是真实存在的，数据也对上，比如  
![[笔记同步助手/images/1fe315da9e8f457169c9fe77e116a30f_MD5.png]]

类似的场景还有很多：

-   **在各种网站搜索整理信息**：知网搜论文、招聘网站比较岗位、电商比价
    
-   **操作 Mac 原生应用**：用 Keynote 做演示、用 Numbers 处理表格、用预览编辑 PDF
    
-   **跨应用工作流**：从一个 App 里复制数据，粘贴到另一个 App，省去来回切换
    

**注意事项**——这些一定要记住：

-   别让它碰微信、社交媒体账号
    
-   别让它碰付费软件的付款页面
    
-   别让它碰公司内部工具和私人资料
    
-   看到权限弹窗**千万别无脑点确认**，看不懂就问它"这个权限会做什么"
    

### 4、插件

点左侧"插件"，你会看到这些功能模块：

![[笔记同步助手/images/de53a5274a7583b59531c67c50846ced_MD5.png]]

-   **Spreadsheets**——处理表格
    
-   **Presentations**——做 PPT
    
-   **Browser Use**——操作内置浏览器搜资料
    
-   **Computer Use**——操作电脑上的软件
    
-   **Gmail / GitHub / Google Drive**——连接外部账号
    

这里可能还会看到 Skill、MCP 这些词，别慌，简单理解：**插件是能力包，Skill 是工作流说明书，MCP 是接工具的通道。** 都是让 Codex 能干更多事。

插件里面还有技能，就是 skill，可以在这个页面进行管理  
![[笔记同步助手/images/4ea5302f160915f7d20fad238e47d907_MD5.png]]

**建议：刚开始只用官方内置插件，别贪多，用到再装。**

### 5、自动化

自动化就是让 Codex 在某个时间点或按某个频率，自动执行你提前设好的任务。比如每天早上帮你整理邮件、每周生成一次项目周报、定时监控某个网页变化。

![[笔记同步助手/images/25ef63bacaee4a31941bccb84a768b81_MD5.png]]

**建议：先把前面的功能玩熟了，再来折腾自动化。**

### 6、设置页

左下角"设置"里有十几个页面，小白只需要关注：

**工作模式**——不是程序员就选"日常工作"，Codex 说话会更通俗

**权限**——先别开最大，熟了再慢慢放开

**个性化**——写上"请默认用中文回答"就行，其他按需加

**发送方式**——建议开启 Command+Enter 发送，防止写长需求时误触回车

其他设置全部保持默认，不用动。

## 四、CLI 使用

很多人以为 CLI 只有程序员能用，其实不是。只要你会打字，CLI 就能帮你从零开始做东西——**你不需要写一行代码，只需要描述你想要什么。**

举个例子：用 Codex CLI 做一个贪吃蛇小游戏。

### 1、打开终端，进入一个空文件夹

```
codex
```

![[笔记同步助手/images/9aded71bdd12b4b3f5ac4b172ec664e6_MD5.png]]

### 2、直接告诉它你要什么

```
帮我用 HTML + JavaScript 写一个贪吃蛇小游戏，要求：
- 用方向键控制
- 有计分功能
- 页面好看一点
```

Codex 会自动创建文件、写代码，完成后你直接用浏览器打开生成的 HTML 文件就能玩。  
![[笔记同步助手/images/b3578702bb8726159094cdfb0d6b5ddb_MD5.png]]

注意，cli 和 codex 桌面版是共享会话内容的，也就是你在 cli 里面对应的目录的 session 在 codex 桌面端也会显示。

![[笔记同步助手/images/5b09d3a897414ebab45466f3f3795df7_MD5.png]]

整个过程你不需要懂代码，只需要描述需求。觉得不满意？继续说"把速度调慢一点"、"加个排行榜"，它会接着改。

### 3、权限模式

CLI 有三个权限等级：

-   **Suggest**——只给建议，不碰你的文件
    
-   **Auto Edit**——自动改文件，但跑命令前会先问你
    
-   **Full Auto**——完全自主，改文件、跑命令全自动
    

想让它全程帮你干活，直接 Full Auto。不放心的话从 Auto Edit 开始。

### 4、App 和 CLI 怎么选

不冲突，看场景：

-   写报告、做文档、操作电脑 → **用 App**
    
-   做项目、写小工具、搞开发 → **用 CLI**
    
-   两个可以同时开，互不影响

## 补充：Codex App、云端 Codex、ChatGPT 有什么区别

很多人搞不清这三个的关系，一张表说清楚：

| 名字 | 大白话 | 适合什么 |
| --- | --- | --- |
| **ChatGPT** | 网页/App 里的聊天助手 | 问问题、写文案、生成图片 |
| **Codex App** | 装在电脑上的 AI 工作台 | ChatGPT 能做的都能做，还能读本地文件、操作电脑 |
| **云端 Codex** | 跑在服务器上的 AI Agent | 电脑关机也能跑任务，不受本地限制 |

记住一个判断标准：

-   一般任务 → ChatGPT 或 Codex 普通对话
    
-   要处理本地文件 → Codex App 项目模式
    
-   要让 AI 持续跑任务不受电脑限制 → 云端 Codex

## 避坑指南

**权限弹窗别无脑点。** 看不懂就问它"这个权限会让你做什么"，它会解释。

**结果不满意别重开对话。** 在原对话基础上继续改，比如"保留结构，语气改口语化一点"。比重新来一遍效果好得多。

**插件别贪多。** 用到再装，内置功能先用起来。

**CLI 报错别慌。** 把错误信息贴给它，让它自己定位和修复，这事它在行。

**🪜要全程开着。** 下载、登录、使用都需要，断了就连不上。

## 附：实用小技巧

**用 @ 精准指定文件。** 在对话框输入 @，可以选择项目目录下的具体文件，让 Codex 只看你要它看的：

![[笔记同步助手/images/6ad6a4db4a312fbdd63861f0cbc71a38_MD5.png]]

**查看剩余额度。** 点击额度显示区域，可以看你的使用情况。我这是 Plus 账号，日常轻度使用是够的：

![[笔记同步助手/images/26203658049683007eedaefb5a77a0f6_MD5.png]]

**模型和速度选择。** 模型选最新的 GPT 5.5 就行。速度一般用"常规"，"快速"是 1.5 倍速但额度消耗也会增加：

![[笔记同步助手/images/5b8c5952e18ff1fa1d5b281268510bf3_MD5.png]]

**CLI 和 App 会话是共享的。** 你在 CLI 里某个目录下的对话，在 Codex App 桌面端也能看到，两边同步。
