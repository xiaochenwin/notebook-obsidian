## 核心技术解析：为何 HTML 成为新一代 PPT 基础

当前 AI 生成 PPT 的底层技术已从 Markdown 转向 HTML。主要原因如下：

-   HTML 天然支持分页式视觉布局，更适合表现 PPT 的“一页一主题”特性。
-   现代 AI 模型（如 Claude、GPT）生成 HTML 的能力显著增强，可精准控制样式与结构。
-   HTML 支持动态元素（如可交互图表、动画、嵌入脚本），为未来智能演示奠定基础。

这一趋势由海外开发者 Sirk 提出并验证，标志着内容创作正进入“语义化+可视化”融合新阶段。

## 高阶技巧：跨 Skill 能力融合

Cloud Code 的真正优势在于其“乐高式”组合能力。以演讲者模式为例：

归葬 PPT 本身不支持演讲者视图，但可通过指令让 AI 将 HTML PPT 中的演讲者模块“移植”到归葬模板中。实现方式如下：

1.  生成归葬风格的 Deck
2.  调用指令：“请为该 Deck 添加演讲者视图”
3.  AI 自动解析源码，注入倒计时、下一页预览、口播稿显示等功能

最终效果：主屏展示精美画面，副屏显示讲稿与提示，完美适配线下演讲需求。这体现了 Agent 不是黑盒产品，而是可拆解、可重组的智能积木。
