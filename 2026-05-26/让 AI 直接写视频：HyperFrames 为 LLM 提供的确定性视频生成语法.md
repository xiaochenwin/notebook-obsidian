## 引言：AI视频生成的不确定性

2025年，视频生成模型呈现井喷式发展。输入一段文字描述，AI能在几十秒内生成一段画面惊艳的视频片段。字节的Seedance 2.0甚至将视频生成成本压至1元/秒，内容可用率从20%升至90%以上。

然而，这些生成式模型存在一个根本性的问题：**内容不可控**。你无法让模型在精确的3.0秒淡入一个特定标题，也无法在5.2秒让柱状图跳到87%——而这些恰恰是商业视频制作中最基础的需求。

同时，专业的视频编辑软件如After Effects和Premiere虽然提供了精准控制的能力，但它们是为人机交互设计的——基于图层的时间线、复杂的菜单和需要视觉判断的关键帧调整，对大语言模型而言几乎是无法操作的。正如HeyGen团队的洞察所言：**传统视频工具和AI大语言模型之间存在不可跨越的鸿沟**。

2026年4月17日，HeyGen开源了一个名为 HyperFrames 的框架，试图弥合这道鸿沟。它的核心理念极其简单：

**Write HTML. Render video. Built for agents.**

---

前几天要给自己的 AI 产品做个介绍视频，放官网用。需求很简单：十几秒，功能演示就行。但光是想到要打开剪映、对着时间轴发呆、导出又要等半天，就一直拖着不想动。

最后实在拖不下去了，想起之前收藏的一个开源项目——**HyperFrames**。试着写了一段 HTML，跑了一条命令，MP4 直接出来了。

​

> 用完之后想说的一句话：**AI 做视频这件事，缺的不是一个更强的 AI，而是一个对的接口。HyperFrames 可能就是这个接口。**

## HyperFrames 是什么？

HyperFrames 是 HeyGen（做出 AI 虚拟人视频那家公司）开源的框架。

官网地址: [https://hyperframes.heygen.com/](https://hyperframes.heygen.com/)

**一句话：写 HTML，就能出视频。** Apache 2.0 协议，完全免费，可商用。

### 基本逻辑

-   用 **HTML/CSS** 画画面，用 **GSAP** 写动画
    
-   给元素加上 `data-start`、`data-duration` 标记时间
    
-   跑一行命令 `hyperframes render`
    
-   MP4 就出来了
    

没有时间线、没有轨道、没有图层概念。你写的是网页，但出来的是视频。

​

## 为什么值得关注？

传统视频工具（剪映、PR、AE）从一开始就是为人操作设计的。拖时间轴、调关键帧、对齐图层——这些对 AI 来说完全没法理解，所以 AI 在视频制作上一直插不上手。

**但 HTML 恰好是 AI 最擅长的语言。** LLM 生成 HTML 代码的能力非常强，这是训练数据里最丰富的部分。

HyperFrames 的思路：把"AI 能写的东西"变成"能看的视频"。

### 几个特点

-   ✅ **确定性渲染**：同一份代码，今天跑和明天跑，输出字节级一致
    
-   ✅ **AI 原生**：不需要剪辑接口，AI 直接写 HTML 就能出视频
    
-   ✅ **完全本地**：不依赖任何云服务
    
-   ✅ **批量友好**：模板 + 循环 = 批量生产线
    

## 5 分钟快速上手

**环境准备**

​

```
node --version
ffmpeg -version
```

**安装**

​

```
# 推荐方式（AI Agent 也能用）
npx skills add heygen-com/hyperframes

# 或直接装 CLI
npm install -g hyperframes
```

**初始化**

​

```
npx hyperframes init my-product-video
cd my-product-video
```

**写代码 — 最简化例子**

​

```



    Hello HyperFrames!





window.__hf = { duration: 5, seek: function(t) {} };
window.__timelines = {};
const tl = gsap.timeline({ delay: 0.5 });
window.__timelines['my-first-video'] = tl;

  tl.to("#headline", { opacity: 1, duration: 0.6 })
    .to("#headline", { x: 300, duration: 2 }, 1);
```

**预览 & 导出**

​

```
# 预览（浏览器实时播放，改完自动刷新）
npx hyperframes preview

# 导出 MP4
npx hyperframes render -o my-video.mp4
```

用 Claude Code（或者 Cursor、Codex），装完 skills 之后直接说：

​

> “用 /hyperframes 做一个 10 秒的产品介绍视频” “包含：标题页、功能介绍页、CTA 页” “风格：深色科技风，紫色渐变主色”

它会从零生成完整的 `index.html`，包含 GSAP 时间线动画、场景切换逻辑。然后跑一条命令，视频就出来了。

流程很简单：**你描述需求，AI 写代码，你验收，出 MP4。** AI 在替你写代码，你在替他验收。

## 3 个实际能用的场景

### 批量信息流广告

跨境电商、SaaS 投放——每个 SKU 一条视频，发抖音发小红书发信息流。模板写好，AI 批量跑，一百条视频一个人一天能搞定。以前外包要几万，现在一个人加一段循环代码就解决了。

### 知识付费内容生产

老师讲完课，把讲义丢给 AI，自动生成章节总结动画、数据图表动画、预告片。一个老师加 AI 加 HyperFrames，差不多等于一个人做出一个内容团队的效果。

### 技术文档视频化

B2B 产品需要给客户演示 API 用法？以前录屏，现在直接让 AI 生成，技术文档直接变成讲解视频。客户理解成本大幅降低，成单率自然上去了。

## 和 Remotion 怎么选？

Remotion 不是开源的，source-available 协议，商用要付费，团队超过 5 人还要额外申请。HyperFrames 是 Apache 2.0，彻底开源，随便商用。

​

| <br> | HyperFrames | 剪映/PR | Remotion |
| --- | --- | --- | --- |
| 需要学剪辑 | 不需要 | 需要 | 需要（React） |
| AI 友好度 | 极高 | 弱 | 中等 |
| 价格 | 免费 | ¥49+/月 | $25+/月 |
| 开源协议 | Apache 2.0 | 闭源 | Source-Available |
| 输出确定性 | 字节级一致 | 不确定 | 确定 |

## 说点真实感受

第一次用完有点意外。不是说他能替代专业剪辑——电影级特效还是得用 AE。但如果需求是**产品介绍、教程、解说**这类内容，HyperFrames 的效率确实是碾压级的。

最让我意外的还是 AI Agent 协作这部分。现在让 AI 做视频已经很成熟了，但是HyperFrames像是专门为 AI Agent 设计，Agent 非常擅长编写结构化良好的代码。

## HyperFrames vs. AI 生成视频：核心对比与各自优势

| 对比维度 | **HyperFrames (代码驱动/程序化)** | **AI 生成视频 (大模型驱动)** |
| --- | --- | --- |
| **核心理念** | **“视频即代码 (Video as Code)”** | **“从文本到画面 (Text-to-Video)”** |
| **创作方式** | 通过**编写 HTML/CSS/JS 代码**，精确指定每一帧的内容。甚至可以利用 Agent 通过对话辅助你写代码。 | 通过**输入文字描述 (Prompt)**，由 AI 模型“理解”后，自动生成连贯的视频画面。 |
| **工作流程** | **代码编辑器**编写 → **预览** → **反复修改代码** → **渲染成片**。这是一个高度可控的工程化过程。 | **输入 Prompt**→ **等待 AI 生成** → 查看结果 → **重新修改 Prompt** 再次尝试。更像是一个探索和筛选的过程。 |
| **核心优势** | \*\* 精准控制、 结构严谨、 高度自定义\*\* | \*\* 视觉冲击力、 极致高效、 极低门槛\*\* |
| **视觉表现力与风格** | 风格取决于你的“编程水平”和创造力，**上限极高**。可以精确实现品牌色、特定动画、动态图表等。对于绚丽或光影复杂的画面，实现成本会比较高。 | **视觉表现力通常在平均线以上**，尤其是 Cinematic 风格。擅长生成超现实、震撼的奇观或特定美术风格（如水墨风）。 |
| **内容可控性与精度** | **极高**。你能**精确到每一个像素、每一帧**的坐标、颜色和动画轨迹。修改视频的某个元素，只需修改对应代码。 | **较低**。无法精确控制特定物体或角色的精确位置和动作。想修改微小的细节，只能重新修改 Prompt，结果可能完全不同。 |
| **效率与学习门槛** | **门槛较高**，需要具备 HTML/CSS/JS 等前端编程知识。需要编写代码，比较费时。但借助 AI 编程助手（Agent），门槛正在降低。 | **门槛极低**，几乎为零。任何会打字的人都能快速上手。几分钟甚至几十秒即可生成一段视频素材。但后续的修改和迭代难以预测。 |
| **版权与费用** | **完全开源免费 (Apache 2.0)**，没有隐藏的按次收费。但需要自己部署渲染环境。 | 通常是**订阅或按量付费**，成本可能因频繁尝试而增加。版权归属需看清楚平台的用户协议，通常商业使用有限制。 |

## 拆解两大阵营的独特魅力

### HyperFrames (程序化生成)：像一位严谨的工程师

它的优势根植于其“代码驱动”的核心：

-   **像写网页一样写视频**
    
    ：它的核心思想是直接用 HTML、CSS 和 JavaScript 来“编写”视频。就像搭建一个网页一样，你能精确控制每一个元素从哪一秒出现、在什么位置、用什么动画效果，所有细节都在你的掌控之中。
    
-   **为 AI 原生而生**
    
    ：它专门为 AI Agent（如 ChatGPT）设计，Agent 非常擅长编写结构化良好的代码。你甚至可以和 AI 对话，描述你想要的视频效果，由它来帮你完成代码编写的工作。
    
-   **完美的确定性**
    
    ：HyperFrames 能保证“相同的输入，永远产出相同的视频”。这对于需要自动化批量生成视频（比如上千个个性化的营销视频）的场景来说，是至关重要的特性。
    
-   **工程化的优势**
    
    ：所有代码都可以纳入 Git 等版本控制系统进行管理，这带来的好处是视频可以像代码一样进行协作、审查、回滚，非常适合需要规范化、持续迭代的团队。
    

### AI 生成视频 (大模型驱动)：更像一位随性的艺术家

它的优势在于强大的生成能力和极低的使用门槛：

-   **惊人视觉，即刻呈现**
    
    ：经过海量数据训练的扩散模型，能够创作出极具冲击力、电影感十足的画面，往往能带来出乎意料的视觉惊喜。
    
-   **生产力的飞跃**
    
    ：对于需要快速产出大量短视频的场景（如电商、社交媒体内容），AI 是效率神器。制作成本可能降至传统方式的几十分之一，效率提升惊人。
    
-   **打破创作的天花板**
    
    ：即使不懂任何专业技术，普通人也能通过寥寥数语“创作”出属于自己的视频，极大降低了视频创作的门槛。很多电商品牌已用它制作场景化视频，获得可观的投资回报。
    

## 如何选择？场景化决策指南

| 应用场景 | 推荐技术方案与原因 |
| --- | --- |
| **搭建自动化视频工厂**（如：千人千面的广告、动态数据报告） | **✅ HyperFrames**它的**确定性、可编程性**和**工程化能力**是自动化流水线的不二之选。 |
| **探索创意灵感/设计概念预告片** | **✅ AI 生成视频**快速生成多种风格版本，激发创意灵感，是绝佳的头脑风暴工具。 |
| **制作交互式/个性化视频内容**（如：在线视频编辑器） | **✅ HyperFrames**技术本质上是渲染网页，能天然融入变量和动态数据，生成个性化视频。 |
| **快速社媒短视频/热点内容** | **✅ AI 生成视频**需要快速响应热点，效率是王道，AI 能在几分钟内产出可用素材。 |
| **制作专业/商业作品**（如：商业广告、品牌宣传片） | **⛏️ 两者结合**先用 AI 生成惊艳的视觉素材，再用 HyperFrames 等工具精确编排、添加动态信息和品牌元素。 |

## 总结

选择哪种方式，本质上是对“控制权”和“想象力”的权衡。

如果你需要的是一个**精确、可靠、可重复**的解决方案，能像管理代码一样管理视频，那么 **HyperFrames 是你的最佳选择**。它的整个技术栈为你提供了强大的确定性。而如果你追求的是**效率、探索性和突破想象的视觉震撼**，那么 **AI 视频生成模型**无疑是更合适的工具，它能帮你快速捕捉灵感。

目前一个很明显的趋势是，两者的界限正在变得模糊。像 **Remotion** 这样的工具，也在积极拥抱 AI 和智能体。未来的视频创作，很可能会是像 HyperFrames 这样的 **“视频即代码”工具**和像 Sora 这样的大模型生成工具深度融合的形态。
