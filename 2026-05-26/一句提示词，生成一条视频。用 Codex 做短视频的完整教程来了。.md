# 最近陆续有朋友问我，你那些视频画面是怎么做的，提示词是什么。

# 其实真的没那么复杂。

所以今天这篇文章，就把我用 Codex 做短视频的完整流程写出来。

从安装到出片，全部写清楚。

​

---

这套工作流的核心工具叫 **Codex**，是 OpenAI 出的 AI Agent 桌面应用。

它本身是做代码的，但搭上一个叫 **HyperFrames** 的插件之后，就变成了一个能直接生成短视频的东西。

你描述你想要什么画面、什么风格、什么文案，它帮你渲染出来。

实测数据是这样的：一条 90s 左右的视频，Codex 大概能改 9 次，之后就会触发 5 小时的额度限制。

先知道这个，别到时候改到一半卡住了。

好了，我们直接开始。

​

---

## 一. 准备工作

先说要准备什么，两件事。

**一是梯子**，科学上网用，Codex 是国外产品。

**二是 ChatGPT Plus 账号**，这里特别说一下，不要直接调用 ChatGPT 的 API。

会很贵。

Plus 订阅走的是订阅额度，一条 90s 的视频反复改 9 次，比调 API 省多了。

​

---

## 二. 安装 Codex

### 1\. 下载

打开 Codex 官方下载页面，根据自己的电脑系统选择对应版本，点击下载。

![[笔记同步助手/images/dbac5d35800331376bf80860a549899d_MD5.png]]

### 2\. 安装

下载完成后，你会得到一个 Codex.dmg 文件。

双击打开它。

![[笔记同步助手/images/23ace4a9815fbda9bf9f4bd7b2580a9b_MD5.png]]

弹出安装窗口，把左侧的 **Codex** 图标按住拖到右侧的 **Applications** 文件夹里。

![[笔记同步助手/images/56f1a7b40ea8b5138d4abcba5f6feae2_MD5.png]]

拖进去就装好了。

​

### 3\. 安装 HyperFrames 插件

打开 Codex，在左侧边栏找到「**插件**」，点进去。

在搜索框里输入 hyperframes。

下面会出现 **HyperFrames by HeyGen**，点安装。

![[笔记同步助手/images/dc38affe3c25f2603035537a1d34f436_MD5.png]]

装好之后，这个工具就有了生成视频的能力。

到这一步，环境准备完了。

​

---

## 三. 制作视频

视频制作分两种。

一种是**有真人出镜口播**的，一种是**纯 AI 生成、不需要真人出镜**的。

分开说。

​

---

### 3.1 真人出镜口播版

这个流程的逻辑是：你先录一段自己讲话的视频，然后让 Codex 帮你套上高级感的 AI 动效画面。

**第一步：录素材，去掉气口**

用 16:9 的画面自己录一段口播视频。

录完之后，打开剪映，用「**智能剪辑**」一键去掉气口。

这一步处理完，视频节奏感会好很多。

**第二步：找一条对标视频**

去找一条你想做成那种风格的视频，下载保存下来。

你想做口播的，就找口播剪辑好的视频；你想做什么风格，就找那个风格的视频。

**第三步：把对标视频发给 Codex 分析**

把刚刚下载的对标视频发给 Codex，用下面这条提示词让它学习和分析：

```
调用 Hyperframes 帮我分析一下附件的短视频，我要怎样给你提要求你才能帮我生成类似的视频？你先学习和分析一下附件视频，如果我想做成附件的这种视频，需要用到哪些动效要求？
```

Codex 会根据你的对标视频，给出一份制作类似视频的提示词模板。

**第四步：把提示词改成自己的内容**

把 Codex 给你的提示词模板复制下来，把里面的内容换成你自己的——你的口播视频路径、你的核心主题、你想要的风格。

下面是我自己真实用过的一条提示词，你可以参考这个结构来写：

```
调用 @hyperframes

你是一名顶级 AI 短视频导演，请基于我的 9:16 真人口播视频 [你的视频路径]，制作一条竖屏高级 AI 工作流风格视频。

核心主题：
"[你的核心主题]"

视频比例：9:16 竖屏
视频时长：[时长]

重要要求：
- 以真人口播为主线
- 不要裁掉人物头部
- 不要让信息卡挡住人脸
- 字幕放在底部安全区上方
- 画面顶部和底部预留安全区
- 适配视频号 / 抖音 / 小红书竖屏观看
- 所有信息卡优先放在人物两侧、上方或下方，不要遮挡主体

整体视觉风格：
- 暗色极简
- 高级科技感
- 半透明玻璃卡片
- UI 浮层
- AI 工作流系统感
- 克制、干净、专业
- 不要赛博朋克
- 不要廉价蓝光
- 不要满屏代码乱飞

整体画面结构：
- 真人口播占画面中间偏下区域
- 关键信息卡在上方 20% 区域出现
- 工作流节点可在人物左右两侧轻微漂浮
- 底部只保留字幕，不堆叠复杂元素

字幕要求：
- 底部黑色半透明字幕条
- 字幕位于底部安全区上方
- 字体简洁高级
- 重点关键词可高亮
- 不要花哨弹跳特效
```

把这个结构填好，发给 Codex，等它跑完，视频就出来了。

​

---

### 3.2 无人出镜版

这个流程更简单。

你不需要录自己，只需要有文案。有产品图更好，没有的话 Codex 也能做。

**第一步：找对标视频，让 Codex 学习**

同样先找一条无人出镜的视频下载下来，发给 Codex，还是用一样的分析提示词：

```
调用 Hyperframes 帮我分析一下附件的短视频，我要怎样给你提要求你才能帮我生成类似的视频？你先学习和分析一下附件视频，如果我想做成附件的这种视频，需要用到哪些动效要求？
```

**第二步：把提示词改成自己的**

同样把 Codex 给的提示词结构复制下来，换成你自己的内容。

无人出镜版的提示词可以参考这个样例：

```
请帮我制作一条参考附件风格的短视频，口播必须和下面文案一模一样，一个字都不要改、不要删、不要重写。

视频规格：
- 比例：9:16 竖屏
- 时长：根据口播自然语速决定
- 风格：暗色科技感、蓝青色霓虹、AI 产品发布片、HUD 界面
- 输出：mp4
- 不需要真人出镜
- 不需要拍摄感，要像高质感 AI 工具发布短片

口播文案：
「[你的文案，一字不改]」

素材：
- [你的产品图或素材路径]
- [说明这张素材在哪句话出现、以什么方式呈现]

动效要求：
[根据 Codex 分析给出的动效建议填入]

字幕要求：
- 必须有中文字幕
- 字幕和口播逐句同步
- 关键词高亮
- 字幕不要遮挡核心画面

声音要求：
- 使用自然中文女声
- 语速稳、有商业短视频节奏
- 背景音乐：暗色科技感、低频、有推进感
- 音乐音量不能盖过口播

特别要求：
- 口播文案必须完全一致
- 不要把文案改成营销稿
- 不要加我没写的口播句子
- 画面可以补充科技 UI、流程图、数据面板和动效，但口播不能变
```

文案换成自己的，素材路径替换，发给 Codex。

等它跑完，视频就出来了。

​

## 写在最后

这套 Codex + HyperFrames 的视频制作流程，核心逻辑其实很简单。

**先找对标，让 Codex 学。**

**再给内容，让 Codex 做。**

没有什么魔法。

但就是这两步，可以让你在完全不会剪辑、不懂设计的情况下，做出那种看起来有点高级的短视频。

当然它也有限制——额度有限，每次需要对提示词反复调整，出来的东西未必第一次就满意。

但比起以前从零学剪辑、学 AE，这个路径已经短太多了。

希望对你有用。

做出来的话欢迎来找我看看效果。

既然看到这里了，觉得有用的话，随手点个赞、在看、转发，也可以给我个星标⭐，第一时间收到推送。
